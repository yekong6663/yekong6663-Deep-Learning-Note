# 任务效用驱动主动触觉盲插接

> **研究主张**：主动触碰的目标不是尽量重建形状，而是在时间、力和扰动受限时，以更少触碰提高最终盲插接成功率。

**周期**：2026-09 至 2027-05（9 个月）

**本机角色**：开发、轻量验证、数据分析、ROS 2 集成、在线推理与服务器调度。

**服务器角色**：TacSL/Taccel/Isaac Lab 高保真仿真、大规模数据生成、PPO 训练与消融。

## 1. 问题、目标与完成标准

机器人夹持插头，在视觉遮挡且定位误差大于装配容差时插入孔或接口。每次触碰获得局部观测，却会消耗时间、增加接触力并可能推移插头。系统必须决定：触哪里、触多少次，以及何时用何种姿态执行插入。

隐状态为孔位平移偏差、角度偏差和间隙；使用粒子信念 $b$ 表示。对执行修正动作 $u\in\mathcal{U}$，成功预测器为 $g_\phi(\Delta-u,c,s)$，当前最佳成功率为：

$$\rho(b)=\max_{u\in\mathcal{U}}\mathbb{E}_{\xi\sim b}[g_\phi(\Delta-u,c,s)].$$

候选触碰 $a$ 的任务效用为：

$$\alpha_{task}(a)=\mathbb{E}_{z}[\rho(b'\mid a,z)]-\rho(b)-\kappa\,\mathrm{cost}(a).$$

系统选择任务效用最大的触点；当成功率达到阈值或预算耗尽时执行最优 $u^*$。项目完成需同时满足：

1. 任务效用策略在相同预算下优于熵驱动、随机、栅格和无触探基线；
2. 成功率预测器与信念成功率均完成 ECE、NLL、可靠性图校准；
3. 仿真覆盖至少三种插头/孔型、三档间隙与多种遮挡先验；
4. 真机阶段使用固定执行器、统一螺旋兜底和预定义统计协议；
5. 配置、随机种子、资产版本、模型和结果均可复现。

## 2. 逻辑架构

```text
视觉先验 / CAD / 容差
          │
          ▼
   重尾粒子信念 b_t
          │
候选触点与触碰原语
          │
          ▼
几何预测 + 触觉测量模型 p(z | ξ, a)
          │
          ▼
粒子滤波（更新、重采样、resample-move、复位）
          │
          ▼
成功预测器 gφ + 最优插入修正 u*
          │
          ▼
任务效用 / EVOI：继续触探或停止执行
          │
          ▼
柔顺插入 → 成功判定 → 日志、校准、分析
```

| 层级 | 内容 | 运行位置 | 主要产出 |
|---|---|---|---|
| L0 | CAD、视觉先验、容差和实验定义 | 本机 | 可版本化 YAML 配置 |
| L1 | 二维轻量信念环境 | 本机 | 算法原型、单元测试、早期主结论 |
| L2 | 信念空间代理环境与 PPO | 本机小规模/服务器主训练 | 摊销策略 |
| L3 | TacSL 或 Taccel 高保真触觉仿真 | 服务器 | 测量模型与 sim-to-real 审计 |
| L4 | ROS 2、传感器与机械臂闭环 | 本机连接真机 | 在线推理和真机数据 |

本机不运行 Isaac Sim/Lab、TacSL、Taccel 大规模任务；所有耗时训练通过 `scripts/submit_remote.sh` 提交服务器。

### W2｜2026-09-08 至 2026-09-14：建立二维插接任务与直接执行基线

**要做什么**

把研究问题先压缩为可计算的二维任务：偏移状态、间隙、插入修正动作和成功判据。

**怎么做**

1. 定义状态 $\xi=(\delta x,\delta y,\delta\theta,c)$；视觉先验使用 90% 高斯 + 10% 宽均匀分布。
2. 定义 25 个离散执行修正动作 $u$，以及固定的插入成功函数 $g(\Delta-u,c)$。
3. 固定评测集：3 档间隙 × 1,000 个偏移种子；所有后续方法复用该评测集。
4. 实现“无触探直接执行”：以当前信念选择 $u^*=\arg\max_u\mathbb E[g]$ 后直接插入。
5. 输出 `success@0`、成功率置信区间、后验误差和运行时间。

**完成标志（2026-09-14 前）**

- 1,000 个 episode 在 60 秒内完成；
- 每个 episode 的真实偏移、选择的 $u^*$、成功标签可回放；
- `success@0` 作为冻结基线写入 `experiments/results/`；
- 单元测试覆盖“容差缩小会降低成功率”和“最优 $u$ 不固定为后验均值”。

### W3–W4｜2026-09-15 至 2026-09-28：实现触碰观测与粒子滤波

**要做什么**

让系统在触碰后能够从多峰先验更新为后验，而不是直接读取真值。

**怎么做**

1. 定义 32 个候选触点和 P-press、L-graze 两种触碰原语。
2. 先实现二维解析观测模型：接触/未接触、接触深度、边法向方向，并加入可控噪声。
3. 实现 2,000 粒子滤波：对数似然更新、ESS 检查、系统重采样、Liu–West 平滑和异常复位。
4. 实现后验可视化：真值、粒子、均值、双峰分量、ESS、成功率 $\rho(b)$。
5. 用已知真值生成的观测做 500 个回放 episode，调节噪声与重采样阈值。

**完成标志（2026-09-28 前）**

- 双峰先验案例中，后验不会被错误塌缩为单高斯；
- 500 个回放 episode 无 NaN、无全零权重；
- 输出 RMSE、ESS、重采样次数、复位率；
- 至少 3 条典型信念演化图保存到 `experiments/results/`。

### W5–W6｜2026-09-29 至 2026-10-12：实现并验证任务效用触点选择

**要做什么**

实现研究的核心：按“触碰后能否提高最终插入成功率”选择触点。

**怎么做**

1. 实现 $\rho(b)=\max_u\mathbb E_b[g]$，确保内部显式搜索 $u$。
2. 对每个候选触点，以 Monte Carlo 采样可能观测，计算 $\alpha_{task}$。
3. 实现四个对照：随机触点、固定栅格、熵下降、协方差下降。
4. 在各向异性容差和双峰先验两类场景中，比较第一触点的位置和预期任务价值。
5. 每种方法在相同 3,000 个评测种子上运行预算 {1,3,5}。

**完成标志（2026-10-12 前）**

- 任务效用、熵、随机、栅格均调用同一滤波器和同一成功函数；
- 产生 `success@1/3/5`、中位触碰数、总成本曲线；
- 有一个“熵明显下降但执行动作不变”的零任务价值反例；
- 该反例中任务效用方法不选择该触点。

### W9–W12｜2026-10-27 至 2026-11-23：摊销策略（PPO）

**要做什么**

判断学习策略能否超过或近似贪心 EVOI，并降低在线决策延迟。

**怎么做**

1. 将滤波器、观测模型和预算封装为 Gymnasium 环境；观测只含信念摘要、已访掩码与预算。
2. 先用贪心 EVOI 生成行为数据，验证策略输入、动作空间和奖励实现。
3. 训练 PPO：奖励为成功、触碰代价和任务效用势函数整形；每 50,000 步在固定验证集评估。
4. 用 5 个随机种子训练；比较 PPO、贪心、熵策略的成功率、触碰数与每步决策时间。

**完成标志（2026-11-23 前）**

- 每个种子都有学习曲线、最佳检查点和冻结评测结果；
- PPO 推理单步延迟低于 5 ms；
- PPO 相对贪心的 `success@3` 差距不低于 -2 pp；
- **决策点 B**：若 PPO 没有超过贪心 2 pp，则后续以贪心 EVOI 为主方法，PPO 只保留为加速消融。

### W13–W16｜2026-11-24 至 2026-12-21：成功率校准与最优停止

5. 输出“成功率—触碰数—时间”三维权衡图，并选择主实验阈值。

**完成标志（2026-12-21 前）**

- 运行日志中可解释每个停止决策：达到阈值、预算耗尽或无正效用动作。

## 5. 实验口径（所有阶段通用）

所有方法共享初始偏移种子、视觉先验、执行器、成功判据、触碰预算和螺旋兜底；只允许改变触点选择策略。必须比较：无触探、随机、栅格、熵/协方差、工业螺旋、贪心任务效用和 PPO 任务效用。

每次评测至少输出：`success@{1,3,5}`、达到 90% 成功率所需触碰数中位数、总时间、峰值力、推移距离、后验误差、ESS、复位率、ECE、NLL、Wilson 置信区间和配对统计检验。
