# 第七章 卷积神经网络（CNN）

本章介绍卷积神经网络的基本思想、卷积层与池化层的计算方式、以及基于矩阵运算的高效实现方法。本章还概述了代表性的卷积网络结构，包括 LeNet、AlexNet 和 VGG。

## 7.1 卷积神经网络的特点

卷积神经网络的主要特点包括：局部感受野、权重共享和池化操作。

局部感受野指每个卷积神经元只连接输入图像中的一小块区域，这有助于捕捉局部空间特征。权重共享指同一个卷积核在整个输入上重复使用，这大幅减少参数数量，并保留平移不变性。

池化层对卷积结果进行下采样，保留重要特征的同时降低特征图尺寸，减轻后续计算压力。

## 7.2 卷积层

### 7.2.1 卷积核与输出形状

卷积层通过多个卷积核对输入进行滑动窗口计算。设输入为 $C$ 通道，大小为 $H \times W$，卷积核大小为 $F \times F$，步幅为 $S$，填充为 $P$，则输出高度和宽度分别为：

$$
H_{\text{out}} = \frac{H + 2P - F}{S} + 1,\qquad
W_{\text{out}} = \frac{W + 2P - F}{S} + 1.
$$

如果使用 $F=3$、$S=1$、$P=1$，输出尺寸可以与输入尺寸保持一致。

### 7.2.2 填充和步幅

填充（padding）是在输入图像边缘补零。它的作用是控制输出尺寸，并让卷积能够覆盖输入边缘的像素。

步幅（stride）决定卷积核在输入上移动的步长。较大的步幅会减小输出尺寸，而较小的步幅则保留更多细节。

### 7.2.3 卷积操作实例

一个二维卷积计算的基本过程如下：

```python
import numpy as np

def conv_single_step(x_slice, W, b):
    return np.sum(x_slice * W) + float(b)
```

完整卷积的前向计算可以表示为：

```python
N, C, H, W = x.shape
F, _, FH, FW = W.shape
out_h = (H + 2*pad - FH) // stride + 1
out_w = (W + 2*pad - FW) // stride + 1
out = np.zeros((N, F, out_h, out_w))

x_pad = np.pad(x, [(0,0), (0,0), (pad,pad), (pad,pad)], 'constant')
for n in range(N):
    for f in range(F):
        for i in range(out_h):
            for j in range(out_w):
                h_start = i * stride
                w_start = j * stride
                x_slice = x_pad[n, :, h_start:h_start+FH, w_start:w_start+FW]
                out[n, f, i, j] = np.sum(x_slice * W[f]) + b[f]
```

这种实现方式直观，但速度较慢。后面介绍的 im2col 方法可以将卷积转换成矩阵乘法，提高计算效率。

## 7.3 池化层

池化层通过下采样减少特征图的空间尺寸，常见的池化方式有最大池化和平均池化。

最大池化会取池化窗口内的最大值；平均池化会取窗口内元素的平均值。

对于池化窗口大小为 $F$、步幅为 $S$ 的最大池化，输出尺寸同样由

$$
H_{\text{out}} = \frac{H - F}{S} + 1,\qquad
W_{\text{out}} = \frac{W - F}{S} + 1
$$

决定。

代码实现如下：

```python
def max_pool_forward(x, pool_h, pool_w, stride=1):
    N, C, H, W = x.shape
    out_h = (H - pool_h) // stride + 1
    out_w = (W - pool_w) // stride + 1
    out = np.zeros((N, C, out_h, out_w))

    for n in range(N):
        for c in range(C):
            for i in range(out_h):
                for j in range(out_w):
                    h_start = i * stride
                    w_start = j * stride
                    x_slice = x[n, c, h_start:h_start+pool_h, w_start:w_start+pool_w]
                    out[n, c, i, j] = np.max(x_slice)
    return out
```

池化层可以让模型对局部平移更鲁棒，同时降低后续层的计算量。

## 7.4 基于矩阵乘法的卷积实现（im2col）

直接实现卷积时，循环结构会导致性能瓶颈。im2col 方法将输入整理成二维矩阵，使卷积可以通过一次矩阵乘法完成。

首先，将输入转换为列矩阵：

```python
import numpy as np

def im2col(input_data, filter_h, filter_w, stride=1, pad=0):
    N, C, H, W = input_data.shape
    out_h = (H + 2*pad - filter_h) // stride + 1
    out_w = (W + 2*pad - filter_w) // stride + 1
    img = np.pad(input_data, [(0,0), (0,0), (pad,pad), (pad,pad)], 'constant')

    col = np.zeros((N, C, filter_h, filter_w, out_h, out_w))
    for y in range(filter_h):
        y_max = y + stride * out_h
        for x in range(filter_w):
            x_max = x + stride * out_w
            col[:, :, y, x, :, :] = img[:, :, y:y_max:stride, x:x_max:stride]

    col = col.transpose(0, 4, 5, 1, 2, 3).reshape(N * out_h * out_w, -1)
    return col
```

然后将卷积核展平成矩阵，进行矩阵乘法：

```python
col_W = W.reshape(F, -1)
out = np.dot(col, col_W.T) + b
out = out.reshape(N, out_h, out_w, F).transpose(0, 3, 1, 2)
```

这种实现方式把卷积转换为高效的 GEMM 操作，适合 CPU 和 GPU 上的批量计算。

### 7.4.1 池化层的 im2col 实现

池化层也可以使用类似的思路，将窗口展开后按行取最大值。

```python
def im2col_pool(x, pool_h, pool_w, stride=1, pad=0):
    N, C, H, W = x.shape
    out_h = (H + 2*pad - pool_h) // stride + 1
    out_w = (W + 2*pad - pool_w) // stride + 1
    col = im2col(x, pool_h, pool_w, stride, pad)
    col = col.reshape(N, out_h, out_w, C, pool_h * pool_w)
    out = np.max(col, axis=4)
    return out.transpose(0, 3, 1, 2)
```

## 7.5 代表性卷积网络结构

### 7.5.1 LeNet

LeNet 是早期的卷积网络结构，主要由卷积层、池化层和全连接层组成。它的设计思想是先提取局部特征，再通过全连接层进行分类。

### 7.5.2 AlexNet

AlexNet 在 2012 年的 ImageNet 比赛中取得突破，成功地将深度卷积网络应用于大规模图像分类。它使用了更深的卷积层、更大的卷积核和 ReLU 激活函数，并采用了 Dropout 来缓解过拟合。

### 7.5.3 VGG

VGG 的设计原则是使用多个 $3\times3$ 卷积核堆叠形成更深的网络。两个 $3\times3$ 卷积的感受野等价于一个 $5\times5$ 卷积，但参数更少，且引入了更多非线性。

VGG 的典型结构是：

- 若干个 $3\times3$ 卷积层
- $2\times2$ 最大池化层
- 最后的全连接层

这种简单、统一的设计使得 VGG 在实际应用中非常经典。
