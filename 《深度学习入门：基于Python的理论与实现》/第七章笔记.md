# 第七章 卷积神经网络

## 7.1 整体结构

- 卷积神经网络（CNN）由卷积层、池化层、激活函数层、全连接层等组成。
- CNN 的特点是局部感受野、权重共享和下采样，适合处理图像等具有空间结构的数据。
- 卷积层负责提取局部特征，池化层负责降低尺寸、保留主要信息，全连接层负责最后的分类。

## 7.2 卷积层

### 7.2.1 全连接层存在的问题

- 全连接层参数量巨大，尤其是输入图像尺寸较大时，参数数量会爆炸。
- 全连接层会破坏输入的空间结构，不擅长处理图像局部相关性。
- 需要更轻量、空间感知的结构来替代全连接层。

### 7.2.2 卷积运算

- 卷积层使用一个或多个过滤器（滤波器）在输入上滑动，执行点积运算。
- 一个卷积核在空间范围内对输入进行加权求和，得到一个特征图。
- 卷积操作可以提取边缘、纹理、形状等局部特征。

### 7.2.3 填充

- 填充（padding）用于在输入周围补零，以控制输出的空间尺寸。
- “valid” 卷积不加填充，输出尺寸减小。
- “same” 卷积加填充，使输出尺寸与输入尺寸保持一致。
- 填充可以避免边界信息丢失。

### 7.2.4 步幅

- 步幅（stride）决定卷积核滑动时的步长。
- 步幅为 1 时，卷积核每次移动一个像素；步幅为 2 时，输出尺寸进一步减半。
- 步幅控制特征图的分辨率和计算量。

### 7.2.5 3 维数据的卷积运算

- 对于图像而言，输入通常是 3 维数据：通道数、图像高度和宽度。
- 每个卷积核也具有相同的通道数，对所有通道做卷积并求和，得到一个输出通道。
- 多个卷积核产生多个输出通道，构成输出特征图。

### 7.2.6 结合方块思考

- 卷积运算可以用“方块”来思考：每个卷积核在输入图像上扫描一个小方块区域。
- 输入和卷积核在每个位置做点积，得到输出特征图中的一个位置值。
- 这种“局部感受野”使得网络能够关注图像的局部结构。

### 7.2.7 批处理

- 为了提高计算效率，CNN 通常对一个 mini-batch 的图像同时处理。
- 输入数据的形状通常为 `(batch_size, channels, height, width)`。
- 卷积层的前向传播可以在批处理维度上并行计算。

## 7.3 池化层

- 池化层用于对卷积特征图做下采样，减少空间尺寸并保留重要信息。
- 常用的最大池化（max pooling）在每个池化区域选取最大值。
- 池化能增强平移不变性，并减小后续层计算量。
- 池化层没有学习参数，只做固定的降采样操作。

## 7.4 卷积层和池化层的实现

### 7.4.1 4 维数组

- 要实现 CNN，需要使用 4 维数组来表示批量图像数据和卷积层的输入/输出。
- 数据形状通常为 `(N, C, H, W)`，其中 `N` 为 batch 大小，`C` 为通道数。
- 卷积权重形状通常为 `(FN, C, FH, FW)`，其中 `FN` 为卷积核数量。

### 7.4.2 基于 im2col 的展开

- im2col 是一种将卷积转换为矩阵乘法的技巧。
- 它把输入图像的卷积区域展开为矩阵的每一行，把卷积核展开为另一矩阵的列。
- 这样可以用高效的矩阵乘法库来完成卷积运算。

### 7.4.3 卷积层的实现

- 卷积层前向传播的步骤：
  1. 用 im2col 展开输入。
  2. 将卷积核展平。
  3. 用矩阵乘法计算输出。
  4. 将结果 reshape 回 `(N, FN, out_h, out_w)`。
- 反向传播时，需要把输出梯度转换回输入形状，并计算权重梯度和偏置梯度。

### 7.4.4 池化层的实现

- 最大池化层前向传播时保存每个池化区域的最大值位置。
- 反向传播时，只将对应最大值位置的梯度传回，其他位置梯度为 0。
- 池化层实现也是基于 im2col / col2im 的方式，可以高效处理批量数据。

## 7.5 CNN 的实现

- 可以用卷积层、ReLU、池化层、Affine 层和 SoftmaxWithLoss 组合构建一个完整的 CNN。
- 常见结构为：`Conv -> ReLU -> Pool -> Conv -> ReLU -> Pool -> Affine -> ReLU -> Affine -> Softmax`。
- CNN 的训练过程与普通神经网络类似，包括前向传播、计算损失、反向传播、参数更新。

## 7.6 CNN 的可视化

### 7.6.1 第 1 层权重的可视化

- 第1层卷积核可以直接可视化为图像。
- 通常第一层学到的滤波器类似于边缘检测器、方向滤波器、颜色滤波器等。
- 可视化有助于理解网络学习到的低级特征。

### 7.6.2 基于分层结构的信息提取

- CNN 的前几层学习简单特征，如边缘、角点。
- 中间层学习组合特征，如纹理、小形状。
- 后面层学习更高级的语义特征，如对象部位和整体形状。
- 这种层次化提取是 CNN 优于传统方法的关键之一。

## 7.7 具有代表性的 CNN

### 7.7.1 LeNet

- LeNet 是最早的经典卷积神经网络之一。
- 它使用多个卷积层、池化层和全连接层，成功解决手写数字识别问题。
- LeNet 证明了卷积网络在视觉任务中的有效性。

### 7.7.2 AlexNet

- AlexNet 在 ImageNet 挑战中取得突破性成果，推动了深度学习的广泛应用。
- 它使用更深的网络结构、ReLU 激活、局部响应归一化和 Dropout。
- AlexNet 的成功展示了大型数据集和 GPU 训练的重要性。

## 7.8 小结

- 第七章介绍了卷积神经网络的基本构造、卷积层与池化层的实现以及 CNN 的可视化。
- CNN 通过局部连接、权重共享和层次特征提取，有效地处理图像数据。
- 经典网络如 LeNet 和 AlexNet 说明了卷积网络在实际视觉任务中的重大价值。
