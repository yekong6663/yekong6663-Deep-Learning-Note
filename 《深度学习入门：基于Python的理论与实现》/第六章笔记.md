# 第六章 与学习相关的技巧

## 6.1 参数的更新

### 6.1.1 探险家的故事

- 参数更新可以理解为在损失函数构成的地形上行走的过程。
- 如果只用简单的 SGD，每次都沿着当前梯度的方向走一步，就像在崎岖山路上用最陡峭的方向前进。
- 这会导致在狭长谷底中来回震荡，收敛缓慢。

### 6.1.2 SGD

- 随机梯度下降（Stochastic Gradient Descent，SGD）是最基本的参数更新方法。
- 更新公式：

```python
w -= learning_rate * grad
```

- 这里的 `grad` 是损失函数对参数的梯度。
- SGD 的优点是实现简单、计算开销低。
- SGD 中每次只用一个 mini-batch 的梯度，因此具有噪声，能够帮助跳出局部极小值，但收敛稳定性较差。

### 6.1.3 SGD 的缺点

- 收敛速度慢，尤其是在梯度方向频繁变换时。
- 在“狭长鞍面”上会出现左右摆动，参数更新不稳定。
- 学习率需要谨慎选择，过小会收敛慢，过大可能发散。

### 6.1.4 Momentum

- 动量法引入了惯性概念，将前一次更新方向保留下来。
- 更新公式：

```python
v = momentum * v - learning_rate * grad
w += v
```

- `momentum` 常取 0.9。
- 动量法能保留前一次更新方向的成分，抑制梯度噪声，在平坦方向上加速，在上下振荡的方向上减缓。
- 它类似于在摩擦力作用下滚动的球，能够更快通过狭长的凹槽。

### 6.1.5 AdaGrad

- AdaGrad 对每个参数使用自适应学习率。
- 更新公式：

```python
h += grad * grad
w -= learning_rate * grad / (np.sqrt(h) + 1e-7)
```

- 其中 `h` 是累积的梯度平方和。
- 当某个参数梯度较大时，它的有效学习率会减小；当某个参数梯度较小时，它的学习率会相对增大。
- AdaGrad 适合稀疏特征，但累计平方梯度会使学习率不断变小，长期训练时可能导致收敛停滞。

### 6.1.6 Adam

- Adam 结合了 Momentum 和自适应学习率。
- 主要公式：

```python
m = beta1 * m + (1 - beta1) * grad
v = beta2 * v + (1 - beta2) * (grad ** 2)
m_hat = m / (1 - beta1 ** t)
v_hat = v / (1 - beta2 ** t)
w -= learning_rate * m_hat / (np.sqrt(v_hat) + 1e-7)
```

- `beta1` 常取 0.9，`beta2` 常取 0.999。
- Adam 具有较强的鲁棒性，是当前深度学习中常用的优化方法。

### 6.1.7 使用哪种更新方法呢

- 对于大多数问题，Adam 是一个稳妥的默认选择。
- 如果希望更好地控制收敛过程，SGD + Momentum 对一些任务具有更好的泛化性能。
- AdaGrad 适用于稀疏特征；Momentum 适用于凸优化和浅层网络。
- 最终要依赖实验比较、学习率调试和验证集结果。

### 6.1.8 基于 MNIST 数据集的更新方法的比较

- 在 MNIST 上，Adam 通常能更快收敛。
- SGD 和 Momentum 可能在最终精度上表现更稳定，但训练时间更长。
- 这章强调了“不同更新方法会影响学习曲线和训练结果”，需要结合具体任务选择。

## 6.2 权重的初始值

### 6.2.1 可以将权重初始值设为 0 吗

- 不能简单地把所有权重都设为 0。
- 如果所有权重初始化相同，隐藏层神经元将完全相同，网络中所有节点的梯度也相同，学习后仍然保持对称性。
- 正确做法是随机初始化权重，使不同神经元获得不同的起始方向。

### 6.2.2 隐藏层的激活值的分布

- 权重大小会影响隐藏层输出分布。
- 如果权重太大，激活值会变得非常大，sigmoid/saturation 激活函数容易饱和，导致梯度消失。
- 如果权重太小，信号会变得太弱，网络也难以学习。
- 需要让前向传播时各层的方差保持在合理范围，使信号在深层网络中不过分缩放或放大。

### 6.2.3 ReLU 的权重初始值

- 对于 ReLU 网络，建议使用 He 初始化（又称 Kaiming 初始化）。
- 公式通常为：

```python
W = np.random.randn(fan_in, fan_out) * np.sqrt(2.0 / fan_in)
```

- 这种初始化方式可以使 ReLU 激活后的信号方差更稳定，有利于深层网络训练。

### 6.2.4 基于 MNIST 数据集的权重初始值的比较

- 在 MNIST 上，不同初始化策略会影响训练速度和初期损失曲线。
- 对于 sigmoid 激活函数，较小的随机初始值更合适；对于 ReLU，则推荐 He 初始化。
- 权重初始化不是唯一因素，但它对深层网络的训练稳定性至关重要。

## 6.3 Batch Normalization

### 6.3.1 Batch Normalization 的算法

- Batch Normalization 对每个 mini-batch 计算均值和方差，然后标准化输入：

```python
mu = np.mean(x, axis=0)
var = np.var(x, axis=0)
x_norm = (x - mu) / np.sqrt(var + 1e-7)
out = gamma * x_norm + beta
```

- `gamma` 和 `beta` 是可学习参数，用于恢复和调整标准化后的值。
- BN 插入到 affine 层和激活函数之间，有助于抑制内部协变量偏移。

### 6.3.2 Batch Normalization 的评估

- Batch Normalization 通常能提高学习速度和稳定性。
- 它允许使用较大学习率，减少对初始化和超参数的敏感性。
- 在训练时使用 mini-batch 的统计量，在测试时使用移动平均的均值和方差。

## 6.4 正则化

### 6.4.1 过拟合

- 过拟合是指模型在训练集上表现很好，但在测试集上表现不好。
- 过拟合通常出现在模型容量过大、训练时间过长、训练数据较少时。
- 解决过拟合的办法包括正则化、更多数据、早停、Dropout 等。

### 6.4.2 权值衰减

- 权值衰减就是 L2 正则化，将参数平方和加到损失函数中：

```python
loss = loss + 0.5 * weight_decay * np.sum(W * W)
```

- 相应的梯度更新中会多出一项：

```python
dW += weight_decay * W
```

- 权值衰减可以抑制权重过大，使模型更平滑，减少过拟合。

### 6.4.3 Dropout

- Dropout 在训练时按一定概率随机丢弃神经元输出。
- 它相当于对网络进行随机子网络采样，减少神经元之间的共适应。
- 测试时不丢弃神经元，而是对输出乘以保留概率，或在训练时缩放权重。
- Dropout 在全连接层中效果明显，能提高泛化能力。

## 6.5 超参数的验证

### 6.5.1 验证数据

- 训练数据通常进一步划分为训练集和验证集。
- 验证集用于调节超参数，不参与模型参数的训练。
- 通过验证集评估不同学习率、正则化强度、网络结构等超参数组合。

### 6.5.2 超参数的最优化

- 超参数优化可以采用网格搜索、随机搜索等方法。
- 常见超参数包括学习率、权重衰减系数、动量、Batch Size、初始化方式等。
- 选择超参数时，要避免在测试集上调参，避免测试数据泄露。

### 6.5.3 超参数最优化的实现

- 实现超参数搜索时，通常在循环中训练多个模型，并保存最优模型和验证结果。
- 需要记录每次实验的超参数和对应的验证误差，便于比较与复现。

## 6.6 小结

- 第六章介绍了训练神经网络时常用的技巧：参数更新、权重初始化、Batch Normalization、正则化和超参数验证。
- 这些技巧决定了网络能否稳定训练并获得良好的泛化性能。
- 在实际项目中，合理选择优化方法、初始化方式和正则化策略，是成功训练深度模型的关键。
